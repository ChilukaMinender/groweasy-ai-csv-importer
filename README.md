# GrowEasy AI CSV Importer

An AI-powered CSV Importer that intelligently extracts CRM lead information from CSV files with different structures using AI.

## Live Demo

Frontend:
https://groweasy-ai-csv-importer-i2th6c7nj-minender.vercel.app

Backend:
https://groweasy-ai-backend-uqor.onrender.com/api/health

## Features

- Upload CSV files
- Drag & Drop support
- CSV Preview
- AI-powered CRM field extraction
- Intelligent field mapping
- Responsive tables
- Import and Skip statistics
- Backend API using Express
- OpenRouter AI Integration

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express
- TypeScript
- Multer
- csv-parser

### AI
- OpenRouter
- Google Gemini 2.5 Flash

## Installation

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```

## Environment Variables

Backend `.env`

```
OPENROUTER_API_KEY=your_api_key
```
